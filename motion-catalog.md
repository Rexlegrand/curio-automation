# Motion Catalog — Curio

Référence pour Claude Code. Chaque reel doit être découpé en **beats** (segments de script), et chaque beat doit recevoir une technique de cette liste — aucun beat sans motion assigné, sauf le hook (3 premières secondes, géré séparément).

## Types de beats (à identifier dans le script avant d'assigner une technique)

- **HOOK** — accroche, 0-3s  
- **FAIT** — affirmation brute, information factuelle  
- **COMPARAISON** — deux éléments opposés ou mis en relation  
- **LISTE** — énumération (3 choses, étapes, exemples)  
- **QUESTION** — question rhétorique posée au spectateur  
- **STAT** — chiffre, statistique, quantité  
- **CAUSE-EFFET** — X entraîne Y  
- **NARRATIF** — mini-histoire, séquence temporelle  
- **DÉFINITION** — explique ce qu'est quelque chose  
- **RÉVÉLATION** — twist, chute, information surprenante  
- **CONCLUSION** — synthèse, message final, CTA

## Règle d'usage pour Claude Code

1. Segmenter le script en beats avant toute génération.  
2. Taguer chaque beat avec un type (HOOK, FAIT, STAT, etc.) — un beat peut avoir un type composite (ex: STAT+COMPARAISON).  
3. Assigner une technique de ce catalogue à chaque beat non-HOOK. Ne jamais laisser un beat sans technique assignée.  
4. Ne pas répéter la même technique de caméra/cadrage plus de 2 fois consécutives dans le même reel — varier entre catégories (caméra, reveal, typo, overlay) pour éviter la monotonie visuelle.  
5. Les techniques de la catégorie 7 (overlay/texture) peuvent tourner en continu par-dessus les autres techniques — elles ne remplacent pas le motion principal du beat, elles l'habillent.
